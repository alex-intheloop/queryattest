# Code of Conduct

## Our standard

We are committed to a respectful, technically rigorous, and harassment-free community. Contributors, maintainers, reviewers, and users are expected to:

- discuss ideas and code without attacking people;
- assume good intent while still asking for evidence;
- give actionable, proportionate review feedback;
- protect private security reports, credentials, and user data;
- acknowledge uncertainty and correct mistakes openly;
- welcome contributors regardless of background, identity, experience, or employer.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, sexualized conduct, deliberate disruption, publishing private information, or pressuring someone to disclose a vulnerability before coordinated remediation.

## Scope

This code applies in repository issues, pull requests, reviews, discussions, release channels, project events, and private communications undertaken on behalf of the project.

## Enforcement

Report conduct concerns privately to the repository maintainers. Include relevant links or screenshots when safe to do so. Maintainers may remove content, lock discussions, reject contributions, temporarily restrict participation, or permanently ban participants depending on severity and recurrence.

Maintainers must avoid conflicts of interest. A maintainer named in a report must not make the final enforcement decision. Reports will be handled as confidentially as practical, subject to legal and safety obligations.

## Attribution

This project-specific policy is informed by common open-source community standards, including the Contributor Covenant, while keeping enforcement language appropriate for a small alpha project.
